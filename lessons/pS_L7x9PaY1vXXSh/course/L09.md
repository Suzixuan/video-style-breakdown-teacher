# L09｜HUD 合成与故障组合

预计 35 分钟。你会把人物、HUD 和 L08 故障分成清楚的三层，并让观众第一眼仍然看到人物。

## 先看参考片在做什么

查看 [event-04](../evidence/events/event-04-00-00-07-400.jpg)。HUD 的框、文字和准星提供稳定坐标；人物在下层故障，却没有失去方向。

## 你会做出什么

一段 3–5 秒人物扫描画面：V1 人物、V2/V3 短 RGB 故障、V4 HUD。关闭装饰层后，人物剪辑仍完整。

## 跟我做

1. 复制 `L08-AFTER` 为 `L09-AFTER`。导入合法取得的透明 PNG/MOV HUD；黑底 HUD 也可以。
2. 把 HUD 放到 V4，覆盖人物但不要覆盖整条序列。若素材带 Alpha，直接保留 `Blend Mode: Normal`。
3. 若 HUD 是黑底，选中它，在 `Effect Controls > Opacity > Blend Mode` 选择 `Screen`；黑色应消失，只留下亮线。
4. 把 HUD Opacity 从 45% 开始。暂停在人物脸部：如果文字比脸更抢眼，降到 25–35%。
5. 用 Position / Scale 把准星对到眼睛或胸口装置。不要让每个 HUD 元素各自无目的漂动。
6. 在 HUD 开头 3 帧为 Opacity 做 `0 → 45%`；结尾 3 帧做 `45% → 0`，避免突然像贴纸一样出现。
7. 把 L08 的 6 帧故障放到一次视觉重音处，其他时间保持人物和 HUD 稳定。
8. 依次关闭 V4、V2/V3 做减法检查：没有 HUD 时人物成立；没有 RGB 时 HUD 层级成立。

## 你现在应该看到

- 轨道从下到上是人物、RGB 副本、HUD，职责清楚。
- 第一眼能认出人物，第二眼才读到扫描信息。
- HUD 的出现和消失有 3 帧淡入淡出，RGB 只出现一次。

## 做错了怎么修

- **HUD 遮住人物**：先降 Opacity，再删掉不重要元素，不要继续加发光。
- **黑底没有消失**：确认 Blend Mode 加在 HUD Clip 上，并试 Screen / Linear Dodge (Add)。
- **像廉价游戏界面**：统一字体、线宽和运动方向；只保留一个主准星。

## 交作业

提交完整时间线截图，以及 HUD 开启/关闭的同帧对比。通过标准：轨道职责可解释；人物始终可读；故障关闭后基础合成仍成立。

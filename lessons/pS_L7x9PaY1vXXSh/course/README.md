# 从零模仿这支黑白金科技广告：12 课 Premiere 实操课

这不是效果清单。每一课都是一份可以把 Premiere 打开后照着做的操作单：先看原片证据，再完成一个很小的作品，最后用肉眼检查结果。

## 开始前只准备这些

- Premiere Pro 当前桌面版，Windows 中文或英文界面均可；文中同时给常用英文控件名。
- 三至五段你有权使用的短视频或静帧。圆形主体（眼睛、表盘、镜头、杯口）最适合前六课。
- 任意一段节奏清楚的音乐，供 L10 使用。
- 新建练习项目 `tech-ad-practice`；自动保存位置不要放在课程仓库内。

参考视频为 1080 × 1920、25fps。练习统一使用竖屏 1080 × 1920、25fps，因此：1 帧 = 40ms，2 帧 = 80ms，4 帧 = 160ms，8 帧 = 320ms。

## 学习顺序

| 阶段 | 课程 | 你真正学会的能力 |
|---|---|---|
| 先会剪 | [L01 帧级短切](L01.md) → [L02 构图对齐](L02.md) | 精确到帧地切；让两个画面拥有同一视觉锚点 |
| 再会接 | [L03 Match Cut](L03.md) → [L04 关键帧推进](L04.md) → [L05 Bezier](L05.md) → [L06 圆形蒙版](L06.md) | 先靠形状和运动完成转场，再用蒙版处理接缝 |
| 学会包装 | [L07 Invert 闪变](L07.md) → [L08 RGB Split](L08.md) → [L09 HUD 合成](L09.md) | 把故障效果当标点，而不是用来遮盖差剪辑 |
| 学会组织 | [L10 手工卡点](L10.md) → [L11 综合复刻](L11.md) → [L12 原创 Capstone](L12.md) | 用声音组织镜头，并把参考片语言迁移成原创作品 |

## 上课规则

1. 一次只做一课。前一课“交作业”没有通过，不叠下一层效果。
2. 保留 `BEFORE` 和 `AFTER` 两条序列；改坏了就回到 BEFORE，不靠无限撤销碰运气。
3. 参数是起点。先输入给定数值看到效果，再按课内“如果……就……”调整。
4. 当前课程不能读取你的 Premiere 工程。你需要按每课要求自己核对，或提交时间线与 Program Monitor 截图供人工复核。

想先理解参考片发生了什么，可阅读 [逐转场证据拆解](../lesson.md)。只想开始做，直接打开 [L01](L01.md)。

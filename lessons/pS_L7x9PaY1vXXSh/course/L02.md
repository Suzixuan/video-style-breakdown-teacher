# L02｜Position / Scale 视觉对齐

预计 25 分钟。不要急着做转场，本课只解决一个问题：切点前后的视觉中心是否在同一个位置。

## 先看参考片在做什么

打开 [event-02](../evidence/events/event-02-00-00-02-480.jpg)。头盔、表盘和眼睛材质完全不同，但圆形主体都靠近画面中心。这是 Match Cut 成立前必须先做的构图工作。

## 你会做出什么

两张切点截图：前一帧和后一帧的圆心基本重合、主体大小接近。暂时不加模糊、闪白或故障。

## 先认识三个控件

- `Window > Effect Controls` 打开效果控件。
- `Motion > Position` 控制主体在画面中的 X / Y 位置。
- `Motion > Scale` 控制整体大小。链条图标开启时保持宽高比例。

## 跟我做

1. 复制 L01 序列并命名 `L02-AFTER`。删除短插入，只保留两个带圆形主体的镜头，放在 V1 首尾相接。
2. 把播放头停在切点前一帧。选中第一个 Clip，打开 `Effect Controls > Motion`。
3. 在 Program Monitor 点扳手图标，打开 `Rulers` 和 `Guides`；拖出一条竖向和一条横向参考线，让交点成为目标圆心。
4. 调整第一个 Clip 的 Position，让圆心落在参考线交点。先只改位置，不改大小。
5. 按右方向键到切点后一帧，选中第二个 Clip，也把圆心移到同一交点。
6. 比较两个圆的直径。调整第二个 Clip 的 Scale，直到它与第一个相差不超过约 10%；从 90–120% 的范围慢慢试。
7. 为了检查，把第二个 Clip 临时拖到 V2 覆盖第一个，在 `Effect Controls > Opacity` 输入 50%。两张图应该像描图纸一样重叠。
8. 对齐后把 Opacity 恢复 100%，将第二个 Clip 放回 V1，按空格播放硬切。

## 你现在应该看到

- 两帧叠加时，两个圆的中心几乎不分叉。
- 纯硬切播放时，眼睛会跟着圆心，而不是突然跳去另一处。
- Scale 只用于匹配大小，没有出现黑边。

## 做错了怎么修

- **圆心对了但仍然跳**：检查两个圆的大小和倾斜方向，先匹配更醒目的那个特征。
- **放大后露出黑边**：Scale 只能增大，或改用构图余量更大的素材。
- **怎么都对不齐**：素材透视差异太大。换一对更正面的圆形主体，不要靠模糊硬救。

## 交作业

提交切点前后两张 Program Monitor 截图，以及一张 50% 叠加检查图。通过标准：圆心偏差约不超过画面宽度 3%，尺寸无明显跳变，未使用任何转场效果。

# L05｜Bezier 加速度

预计 20 分钟。本课不增加新镜头，只改 L04 的运动曲线，这样你能真正看懂 Bezier 改了什么。

参考 [event-03](../evidence/events/event-03-00-00-04-200.jpg) 中眼睛向机械虹膜的持续推近：本课只练运动速度，不假定原作者使用了同一条曲线。

## 你会做出什么

两个起止画面完全相同的版本：Linear 匀速版和 Bezier 加速版。播放时能明确说出哪一个在末端更有冲击。

## 先理解插值

Interpolation（插值）决定两个关键帧之间怎么走。Linear 是等速；Bezier 允许先慢后快或先快后慢。它不改变起点和终点，只改变中间速度。

## 跟我做

1. 在 Project 面板复制 `L04-AFTER` 两次，命名 `L05-LINEAR` 和 `L05-BEZIER`。
2. 打开 BEZIER，选中推进 Clip，在 Effect Controls 展开 Scale。
3. 右键第一个 Scale 关键帧，选择 `Temporal Interpolation > Ease Out`；右键最后一个，选择 `Ease In`。
4. 展开关键帧图形。若看到 Value Graph / Velocity Graph 选项，切到 Velocity 观察速度曲线。
5. 轻拖最后一个关键帧前的速度手柄，让曲线在末端前明显加速，但不要形成尖锐折返。
6. 依次播放 LINEAR 和 BEZIER。若差异看不出，临时把区间缩到 6 帧；若末端像撞墙，把终点前的手柄放缓。

## 你现在应该看到

- 两个版本的第一帧和最后一帧构图相同。
- BEZIER 的中间帧分布不同：画面不是每帧增加同样大小。
- 播放时出现速度重音，但结束处没有抽动或反弹。

## 做错了怎么修

- **两个版本构图不同**：你误改了 Scale 数值。复制 LINEAR 重做，只改插值。
- **运动突然停住**：Ease 太重，缩短手柄或改回默认 Bezier。
- **曲线反向**：撤销手柄编辑，确认 Scale 值始终从小到大。

## 交作业

提交 LINEAR 与 BEZIER 的并排预览，以及 Effect Controls 曲线截图。通过标准：起止数值一致，只有速度感不同；能用一句话描述重音出现在开头还是结尾。

## 能力边界

Bezier 是 `PR-native` 的参数插值。它不会替素材补出运动模糊或不存在的 3D 视角。

# L07｜Adjustment Layer 与 Invert 闪变

预计 20 分钟。你会学会把效果放在独立调整图层上，因此随时可以关闭，不破坏源素材。

## 先看参考片在做什么

打开 [event-05](../evidence/events/event-05-00-00-10-400.jpg)。人物姿态基本不变，亮度极性在极短时间翻转。反相是视觉标点，不是整段风格。

## 你会做出什么

切点上方只有 1–2 帧的负片闪变。正常播放有冲击，暂停时能准确找到它，关闭调整图层后底层剪辑完整。

## 跟我做

1. 新建 `L07-BEFORE` 和副本 `L07-AFTER`，把一个高对比人物镜头放 V1。
2. 在 Project 面板底部点击 `New Item > Adjustment Layer`；尺寸和帧率保持序列默认，命名 `AL-Invert`。
3. 把它拖到 V2，位置对准你想强调的切点。
4. 将播放头吸附到切点，向前数 2 帧，用 `Ctrl+K` 或 Razor 把调整图层裁成 2 帧。
5. 打开 `Window > Effects`，搜索 `Invert`，拖到 V2 的调整图层上，不要拖到 V1。
6. 播放后比较 1 帧和 2 帧版本。若 2 帧太刺眼，优先缩成 1 帧，而不是持续降低对比。
7. 点击 V2 轨道的眼睛图标关闭该层，确认 V1 仍能完整播放。

## 你现在应该看到

- 时间线上 V2 只有极短的一小块调整图层。
- Effect Controls 显示 Invert 属于调整图层，而不是源 Clip。
- 闪变结束后画面立即恢复，不持续频闪。

## 做错了怎么修

- **整段都变负片**：调整图层太长，放大时间线裁到 1–2 帧。
- **关闭 V2 后仍反相**：效果误加到了 V1；从 V1 删除，再拖到调整图层。
- **观看不适**：降低预览亮度，停止循环播放，并减少高反差闪变次数。

## 交作业

提交一张能看清 V1/V2 和 1–2 帧长度的时间线截图。通过标准：效果只存在于调整图层；关闭 V2 后源片正常；整段只出现一次短闪。

# 教案模板（lesson.md 必读）

写作 `lesson.md` 时严格按此结构。完整样例见 `examples/sample-first-30s/lesson.md`；`validate_lesson.py` 按本文件的必需章节清单校验。

## 必需顶层章节

1. `先看结论`：3 条最值得先学的原则，直接回答"这支片靠什么成立"。
2. `素材与证据`：源参数、模式、证据数量、token 强度区间、证据入口（清单/概览/波形）。
3. `节奏地图`：表格，列为 时间 | 叙事/视觉任务 | 节奏单位 | 主要连接方式。
4. `逐转场教学`：每个事件一节 `T0X 标题`。
5. `PR 复刻工程`：序列与轨道、建议搭建顺序（结构剪辑→关键帧与节奏→合成与遮罩→调色与声音）。
6. `分层练习`：10 分钟单一原则 / 30 分钟完整转场 / 迁移挑战（禁止沿用原片主体）。
7. `自测与交作业`：勾选清单。
8. `教程链接`：按学习顺序编号；标注检索日期快照与播放量（未核实写"未核实"）。
9. `能力边界`：明确 PR-native / PR-approximation / AE-preferred / 3D-source-required 的分界。

## 每节转场课 T0X 必需子节

按此顺序，每节都有且只有这些子节：

1. `时间码证据`：列出事件窗口内关键帧的时间码≈帧号，并链到对应事件表图片。
2. `观察`：只写证据里看到的（中心位置、亮度极性、颜色边缘、形状连续性、时长）。
3. `判断与置信度`：给效果命名＋置信度（高/中/低），并注明"是否使用某插件无法从成片确定"。
4. `原理`：用一句视觉/认知机制解释为什么成立（如"观众先追踪中心，再读取对象"）。
5. `Premiere 操作`：编号步骤，只写 PR 原生可复刻的动作（标记、轨道、Motion、混合模式、调整图层、遮罩）。
6. `参数起点`：具体数值（帧数、Scale%、偏移 px、Opacity%），注明是复刻起点。
7. `为什么这样设`：解释每个关键数值的依据（帧数对应感知/节奏，尺度变化不抢匹配等）。
8. `失败症状与修正`：至少 3 条"若像 X，先做 Y"的对照。
9. `迁移思路`：把主体替换成另一组对象的例子。
10. `练习`：明确素材与帧数限制的练习任务。
11. `验收`：可逐帧检查的标准（对齐误差、稳定帧数、可关层验证）。
12. `教程`：1–3 个链接（Adobe 官方优先，其次 YouTube/Bilibili），标注日期快照。
13. `能力边界`：标注本节的 PR-native / PR-approximation / 3D-source-required 归类。

## 写作铁律

- 观察与判断分开写；禁止把推断写进"观察"。
- 每个"Premiere 操作"必须对应一个具体可执行的 PR 动作，禁止"加一点特效"这类模糊指令。
- 参数全部标注为复刻起点；禁止出现"原片参数""原作者预设""exact preset"式断言。
- 声音瞬态、标记（M）、波形对齐等节奏依据要落到具体时间码。
- 提到 3D 效果（机械透视、真实运镜）时明确"PR 不负责凭空制造"。
- 有高反差 1–2 帧闪帧时，末尾加闪烁安全提示。

## 命名与文件约定

- 教案文件固定为 `lesson.md`，与其证据放在同一输出目录。
- 证据目录结构由 `analyze_video.py` 决定：`evidence/overview/`、`evidence/events/`、`evidence/waveform.png`、`evidence/analysis_manifest.json`。
- 教程快照由 `collect_tutorials.py` 决定：`tutorial-research-auto/tutorial-research.json` + `.md`。
- 教案内证据链接用相对路径，便于整个输出目录整体移动。
